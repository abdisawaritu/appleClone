# Apple Clone

A responsive Apple homepage clone developed as a group collaboration project to practice Git and GitHub workflows, including repository management, branching, commits, pushing, pull requests, code review, merging, and conflict resolution.

---

## Project Overview

This project is a recreation of the Apple homepage using the frontend technologies and resources provided for the exercise.

The primary purpose of this project is not only to reproduce the webpage but also to provide practical experience with professional Git and GitHub collaboration workflows.

Each team member is responsible for a specific section or component of the webpage and works independently on a dedicated Git branch.

---

## Technologies Used

- HTML5
- CSS3
- Bootstrap
- JavaScript
- Git
- GitHub
